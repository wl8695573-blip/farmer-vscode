# 使用说明

## 安装

打开 VS Code 扩展面板右上角的“…” →“从 VSIX 安装”，选择从 [Releases](https://github.com/wl8695573-blip/farmer-vscode/releases/latest) 下载的 `code-whip-0.8.3.vsix`。更新后按 Ctrl+Shift+P，执行“重新加载窗口”。

## 使用

1. 打开代码文件，或新建未命名文件并在右下角选择代码语言。
2. 语言服务新增红色 Error 诊断时，立即启动鞭子动画；不再等待 1.5 秒、分号或冷却，也没有次数配额。
3. 修好后再犯同样的错误，会再次抽。同一条红标持续存在或仅移动行号时，诊断刷新不会反复抽；同一批诊断新增多个错误时播放一次动画。

无需运行或保存代码。黄标警告不触发。反馈跟随当前编辑器的诊断，语言服务本身的更新时间决定红标出现速度；没有语言服务或没有红标时不会自行编造错误。

## 错误注释

示例：`你他妈怎么蠢得跟猪一样？第3行第9列：少了“}”，他妈把它补上！`

注释显示在错误行末尾，悬停可查看完整台词、错误编号和原始诊断。同一行有多条错误时显示首条，悬停可查看全部。红标消失时注释同步消失，不写入文件、不自动保存。

缺少符号、类型不匹配、未定义名称、字符串未闭合等常见诊断有对应台词。无法归类时直接使用原始报错；行号是语言服务标记的位置，不保证就是根因所在的那一行。

## 修改设置

点击底部“农场主”，或按 Ctrl+Shift+P 搜索“农场主”打开设置。可修改启用状态、台词语言、错误注释、材质、抖动、鞭响、音量和减少动态效果。修改后点击“保存设置”。

设置页提供“预览鞭子”。暂停/恢复、重启桌面组件、清除当前文件虚拟注释可通过命令面板执行。开启减少动态效果会隐藏鞭子。

## 代码

`extension/src/extension.js` 连接 VS Code 诊断、虚拟注释、设置和桌面组件；`diagnostics.js` 判断红标的新增和消失；`messages.js` 改写报错原因；`desktop` 包含鞭子和窗口渲染。

源码采用 MIT 许可。运行不依赖 npm 包、TypeScript 解析器、Python 或网络。重新编译桌面组件使用 `scripts/build-desktop.ps1`；打包使用 `python scripts/package.py`；开发检查使用 `node tests/diagnostics.test.js`。Python 仅是打包工具，用户使用扩展不需要安装。
